# Process Identity Framework

Исследование непрерывности сложных процессов.

## Вопрос

Что сохраняет систему собой при изменениях?

## Идея

Важен не только результат, но и процесс его формирования.

Состояние + История + Инварианты = Непрерывность

## Импринт

Импринт описывает устойчивые свойства процесса:

- модель мира;
- принципы принятия решений;
- цели;
- ограничения;
- историю изменений.

## Подход

Гипотеза → Проверка → Критика → Улучшение

## Области

- автономные системы;
- AI governance;
- идентичность процессов;
- непрерывность сложных систем.
